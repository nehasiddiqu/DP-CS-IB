# B2 Programming Lab

Visual, interactive lessons for **IB DP Computer Science, Theme B2: Programming**, in Python and Java.

**Live site:** https://nehasiddiqu.github.io/DP-CS-IB/b2-programming-lab/

## What's inside

18 lessons covering B2.1 to B2.5:

| Unit | Lessons |
|---|---|
| B2.1 Programming fundamentals | Variables and data types · String manipulation · Exception handling · Debugging and trace tables |
| B2.2 Data structures | Static and dynamic structures · Arrays and lists · Stacks · Queues |
| B2.3 Programming constructs | Sequence · Selection · Loops · Functions and modularisation |
| B2.4 Programming algorithms | Big O · Linear and binary search · Bubble and selection sort · Recursion (HL) · Recursive algorithms (HL) |
| B2.5 File processing | Reading, writing and appending files |

Every lesson has:

- **Do Now** starter with a 5-minute timer
- **Learn** section with analogies, diagrams, interactive visualisers and line-by-line code explanations
- **Hinge questions** to check understanding
- **Task 1**: 10-minute individual task
- **Task 2**: group scenario task with roles
- **Home learning**: exam-style questions with marks and mark schemes

Use the **Python / Java** switch to change every code example, and **Teacher mode** to show delivery notes and all answers.

The whole site is a single `index.html` file with no build step.
